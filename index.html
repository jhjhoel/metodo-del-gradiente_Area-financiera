Caso de estudio

Planificación financiera y distribución de recursos entre unidades de una empresa boliviana.

CASO SIMULADO · BOLIVIA

Una empresa, cuatro áreas,
una decisión coordinada.

Una empresa mediana con operaciones en el eje troncal boliviano necesita distribuir su presupuesto operativo anual. Las áreas compiten por recursos, pero también dependen unas de otras para cumplir sus objetivos.

Justificación del modelo

Se plantea un sistema lineal simétrico y definido positivo como representación simplificada de las relaciones de asignación y coordinación presupuestaria. Los términos diagonales representan la capacidad o peso propio de cada unidad; los términos fuera de la diagonal representan interdependencias entre áreas. El vector independiente representa necesidades financieras estimadas para el periodo.

El sistema es un modelo académico de asignación, no una estimación econométrica ni una optimización completa de cartera. Los coeficientes son supuestos ilustrativos que permiten estudiar estabilidad, sensibilidad y convergencia numérica.

Solución de referencia

La solución numérica de referencia se obtiene mediante factorización de Cholesky, apropiada para matrices simétricas definidas positivas.

Procedimiento directo

Descomposición A = LLᵀ

CHOLESKY

Primero se resuelve L y = b mediante sustitución hacia adelante. Después se resuelve Lᵀ x = y mediante sustitución hacia atrás. El vector x obtenido es la referencia para medir los errores de los métodos iterativos.

Conclusiones financieras

El modelo permite observar cómo una variación de costos o de necesidades entre áreas cambia la solución del sistema. Los resultados representan una distribución matemática bajo los supuestos definidos, por lo que cualquier decisión empresarial real requeriría datos contables verificados, restricciones operativas y validación de responsables financieros.
